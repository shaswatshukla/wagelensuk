# Updating the rules

1. Read the current Appendix Skilled Worker, sponsor guidance and relevant Statement of Changes on GOV.UK.
2. Record exact paragraphs, primary URLs, effective dates and differences in `rules-spec.md`.
3. Seek solicitor review for ambiguity and transitional cases. Unconfirmed interpretation stays REVIEW.
4. Update the runtime JSON version, lastVerified, rule sources and parameters together.
5. Add independent worked examples, including equality, below-threshold and missing-evidence cases.
6. Run tests, coverage, production build and browser privacy checks. Record real results.
7. Obtain owner publication approval. Do not imply that research dates indicate solicitor review.
